# Hermes-сервер для новичков

Набор скриптов и инструкций: как за один вечер развернуть на своём VPS личного ИИ-агента Hermes с подпиской Claude, хранилищем на Яндекс.Диске, голосом, Telegram-ботом и бесплатными LLM-провайдерами. Работать с ним можно из Hermes Desktop (Windows), Telegram и Android.

> Статус: **черновик 0.1**. Скрипты прошли статический анализ и один прогон в контейнерах Ubuntu 24.04 и 22.04. После прогона исправлены 3 ошибки (см. таблицу), исправления ещё не перепроверены. На настоящей VPS ничего не запускалось.

## Что понадобится заранее
- VPS с Ubuntu 22.04 или 24.04: минимум 2 vCPU / 4 ГБ RAM / 40 ГБ (с голосом и рабочим столом лучше 4 vCPU / 8 ГБ). См. docs/01.
- Компьютер с Windows 10/11 (PowerShell; PuTTY по желанию).
- Подписка Claude Pro или Max (своя).
- Аккаунт Яндекса (для Яндекс.Диска).
- Аккаунт Telegram (по желанию).
- Телефон с Android (по желанию).

## Быстрый старт
1. Купите VPS и подключитесь по SSH: docs/01, docs/02.
2. На сервере:
   ```bash
   apt update && apt install -y git
   git clone https://github.com/satelit-cell/hermes-server-kit.git hermes-setup && cd hermes-setup
   sudo bash scripts/install.sh
   ```
3. В меню выбирайте модули по порядку (или `a` для всех): docs/03.
4. Установите Hermes Desktop на ПК и подключите к серверу: docs/04.

## Состав
| Модуль | Что делает |
|---|---|
| 01-base | пользователь, SSH-ключ, firewall, swap, обновления |
| 02-hermes | Hermes Agent (последняя версия), плагины, службы |
| 03-desktop-claude | рабочий стол xfce для входа в Claude (KYC), Claude CLI |
| 04-storage | Яндекс.Диск как ~/cloud, выгрузка медиа, Obsidian |
| 05-freellm | Docker, FreeLLMAPI, поиск бесплатных провайдеров |
| 06-voice | распознавание речи gigastt (по желанию) |
| 07-telegram | Telegram-бот (по желанию) |
| 08-remote-access | Tailscale для Android |
| 09-amnezia | памятка по Amnezia VPN (по желанию) |

Утилиты: `scripts/tools/` (rdp-on/off, save-resources, healthcheck, harden-ssh).

## Что проверено
Прогон в Docker (чистые контейнеры Ubuntu 24.04 и 22.04 без systemd, каждый модуль запускался дважды):

| Что | Результат |
|---|---|
| Синтаксис и shellcheck всех скриптов | проверено, замечаний нет |
| 01-base, 09-amnezia | проходят на 24.04 и 22.04 |
| 02-hermes | Hermes v0.23.1 ставится на обеих версиях; плагин provider-limits в первом прогоне не поставился (исправлено: ставится из GitHub, не перепроверено) |
| 03-desktop-claude | xfce, xrdp (слушает только 127.0.0.1), Firefox, Claude CLI ставятся; плагин подписки Claude в первом прогоне не поставился (исправлен идентификатор `claude-subscription-directsdk`, не перепроверено) |
| 04-storage | rclone ставится; без данных Яндекса останавливается штатно; монтирование и Яндекс не проверялись |
| 05-freellm | в контейнере Docker-демона нет: проверена только установка скриптов поиска; сборка и запуск FreeLLMAPI не проверялись |
| 06-voice | на 24.04 gigastt и модель ставятся; на 22.04 gigastt не работает (нужен glibc 2.38+), модуль теперь это определяет и пропускается |
| 07-telegram | запись в .env (права 600, без дублей при повторе) работает; реальный бот не проверялся |
| 08-remote-access | Tailscale ставится; вход и привязка портов не проверялись |
| Повторный запуск (идемпотентность) | 01, 02, 05, 07 ведут себя корректно при втором запуске |
| Службы systemd --user, ufw, swap, linger, xrdp с экраном, rclone-монтирование | не проверено (нет в контейнере) |
| Вход в Claude, OAuth Яндекса, Telegram | выполняется человеком |
| Полный прогон «с нуля» на чистой VPS | не проверено |

Полный прогон на чистой VPS не делался (решение автора). Рекомендация: Ubuntu **24.04** (голос работает только на ней).

## Безопасность
- В скриптах нет ключей, токенов и IP. Секреты вводит пользователь; пароли вводятся скрытно.
- Наружу открыт только SSH. Рабочий стол (3389), панель (9119), gateway (8642) и FreeLLMAPI (3001) доступны только локально, через SSH-туннель или Tailscale.
- Читайте раздел «Риски» в docs/00.
