# 08. Голос (gigastt)

Модуль 06 ставит локальное распознавание русской речи GigaAM v3 через gigastt (~0.8 ГБ RAM, ~7 с на минуту звука). Голосовые из Telegram и Desktop превращаются в текст на сервере.

**Требуется Ubuntu 24.04** (gigastt собран под glibc 2.38+). На 22.04 модуль сообщит об этом и пропустится.

Установка: `sudo bash scripts/install.sh --only 07` (запускается от hermes автоматически).
Проверка: `curl http://127.0.0.1:9876/ready` и `systemctl --user status gigastt`.
Выключить для экономии памяти: `systemctl --user stop gigastt`.

Голосовые файлы нигде не хранятся: скрипт `media-offload` удаляет их через 30 минут.
Если на сервере меньше 6 ГБ RAM, модуль предупредит и спросит подтверждение.
