# 07. Бесплатные LLM-провайдеры (FreeLLMAPI)

FreeLLMAPI — локальный шлюз: несколько бесплатных провайдеров за одним адресом `http://127.0.0.1:3001/v1`, с автоматическим переключением при лимитах. Модуль 05 ставит его и регистрирует в Hermes как провайдера `freellmapi` (модель по умолчанию НЕ меняется).

## Открыть панель на ПК
```powershell
ssh -L 3001:127.0.0.1:3001 hermes@<IP-СЕРВЕРА>
```
Затем в браузере: http://localhost:3001. Логин и пароль лежат на сервере: `cat ~/services/freellmapi/dashboard.cred`. [СКРИН: панель]

## Добавить ключи
1. Зарегистрируйтесь у провайдера (один аккаунт на провайдера!) и получите API-ключ. Список и лимиты: `python3 -I ~/services/free-llm-tools/find_free_llm.py -q gpt-oss`.
2. Панель → Keys → добавить ключ нужного провайдера.
3. Панель → Fallback Chain: упорядочите модели (большие и надёжные выше).
4. Проверка живым запросом: `python3 -I ~/services/free-llm-tools/probe_providers.py`.

## Правила
- Не отправляйте через бесплатные тарифы личные и рабочие данные.
- Не заводите несколько аккаунтов у одного провайдера и не используйте «ротаторы».
- Бесплатные модели исчезают: раз в сутки таймер `free-models-diff` сохраняет отчёт об изменениях в `~/services/free-llm-tools/reports/`.
