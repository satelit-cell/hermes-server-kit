# 00. Что получится, сколько стоит, какие риски

## Схема
```
Ваш ПК (Windows)                           VPS (Ubuntu)
 ├─ Hermes Desktop  ──── SSH ────────────►  Hermes gateway + агент
 ├─ Obsidian        ── WebDAV ──►  Яндекс.Диск ◄── rclone-монтирование (~/cloud)
 ├─ Amnezia VPN     ──────────────────────►  защищённый доступ к серверу
 Телефон
 ├─ Telegram        ──────────────────────►  бот → gateway
 └─ Hermes Android  ── Tailscale ─────────►  gateway :8642, панель :9119
```
Агент использует вашу подписку Claude через официальный Claude Code CLI. Бесплатные модели подключаются через локальный шлюз FreeLLMAPI.

## Ресурсы (ориентиры с нашего сервера)
| Компонент | RAM |
|---|---|
| Hermes (gateway + dashboard) | 0.5-1 ГБ |
| Рабочий стол xfce+xrdp (когда включён) | ~0.4 ГБ |
| gigastt (голос) | 0.8-1.6 ГБ |
| FreeLLMAPI | ~0.1 ГБ |
| rclone-кэш | до 0.5 ГБ диска |

Сервер на 4 ГБ: без голоса, рабочий стол включать только на время входа. Сервер на 8 ГБ: всё сразу.

## Сторонние компоненты
- Плагин `provider-limits` (лимиты провайдеров) ставится из чужого GitHub-репозитория JaimeMarques/hermes-provider-limits, это не официальный плагин. Он необязателен: если не нужен, пропустите.
- Hermes Android (rusty4444) и FreeLLMAPI (tashfeenahmed) тоже сторонние проекты.

## Стоимость
VPS от нескольких сотен рублей в месяц (зависит от хостинга и тарифа) + ваша подписка Claude. Остальное бесплатно.

## Риски (прочтите до установки)
1. **Условия использования Claude.** Hermes работает с подпиской через официальный Claude Code CLI. Правила Anthropic для подписок и автоматизации меняются: проверьте актуальные условия Claude Pro/Max и не используйте один аккаунт для чужих людей. Ответственность на вас.
2. **KYC и аккаунт.** Вход выполняется из браузера на сервере, то есть с IP хостинга. Возможны дополнительные проверки. Используйте только свой аккаунт.
3. **Бесплатные LLM-провайдеры.** Бесплатные тарифы часто используют запросы для обучения. Не отправляйте через них личные, рабочие и платёжные данные. Один аккаунт у одного провайдера, без «ротаторов» аккаунтов.
4. **Агент выполняет команды.** Hermes может читать и менять файлы и запускать программы на сервере. Не давайте ему доступа к тому, что нельзя потерять. Делайте копии важного.
5. **Ключи и токены.** Хранятся в `~/.hermes/.env` (права 600). Не публикуйте их, не вставляйте в чаты.
6. **Открытые порты.** Не открывайте 3389, 8642, 9119, 3001 в интернет.
