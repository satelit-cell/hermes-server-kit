# 02. Подключение с Windows

## Вариант A: PowerShell (рекомендуется, ничего ставить не нужно)
1. Нажмите Win, наберите `PowerShell`, откройте.
2. Проверьте SSH: `ssh -V` (должна показаться версия). Если команда не найдена: Параметры → Приложения → Дополнительные компоненты → **Клиент OpenSSH**.
3. Создайте ключ (на запросы пароля нажмите Enter):
   ```powershell
   ssh-keygen -t ed25519
   ```
4. Покажите **публичный** ключ и скопируйте строку целиком:
   ```powershell
   Get-Content $env:USERPROFILE\.ssh\id_ed25519.pub
   ```
   Она начинается с `ssh-ed25519`. Приватный файл `id_ed25519` (без .pub) никому не показывайте.
5. Первый вход (IP и пароль из письма хостинга):
   ```powershell
   ssh root@<IP-СЕРВЕРА>
   ```
   На вопрос про fingerprint ответьте `yes`. [СКРИН: первый вход]
6. Положите свой ключ на сервер (выполните в PowerShell на ПК):
   ```powershell
   type $env:USERPROFILE\.ssh\id_ed25519.pub | ssh root@<IP-СЕРВЕРА> "mkdir -p ~/.ssh && cat >> ~/.ssh/authorized_keys"
   ```

## Вариант B: PuTTY
Скачайте PuTTY с putty.org, введите IP, порт 22, нажмите Open, войдите как root. Для ключей используйте PuTTYgen (Generate → Save private key → скопируйте текст из верхнего окна в authorized_keys на сервере).

## Если не получается
- `Connection timed out`: проверьте IP, брандмауэр сети, статус сервера в панели хостинга.
- `Permission denied`: неверный пароль (вставка в PowerShell невидима, это нормально).

**Ожидаемый результат:** вы видите приглашение `root@...:~#` на сервере.
