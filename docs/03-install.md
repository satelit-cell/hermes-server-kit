# 03. Запуск установки

На сервере (после входа как root):
```bash
apt update && apt install -y git
git clone https://github.com/satelit-cell/hermes-server-kit.git hermes-setup
cd hermes-setup
sudo bash scripts/install.sh
```
Появится меню модулей. Устанавливайте по порядку: **01 → 02 → 03 → 04 → 05**, остальные по желанию. Клавиша `a` ставит всё подряд.

| Номер | Что | Что спросит |
|---|---|---|
| 01 | база | скопировать ли ключи root для пользователя hermes (ответьте Y) |
| 02 | Hermes | ничего |
| 03 | рабочий стол и Claude | пароль для рабочего стола (12+ символов) |
| 04 | хранилище | логин Яндекса и пароль приложения (см. docs/06) |
| 05 | бесплатные провайдеры | ничего (ключи провайдеров позже, docs/07) |
| 06 | голос | подтверждение, если мало памяти |
| 07 | Telegram | токен бота и ваш ID (docs/09) |
| 08 | Tailscale | войти по ссылке (docs/11) |
| 09 | Amnezia | только памятка (docs/10) |

Подсказки:
- Повторный запуск безопасен: уже сделанное пропускается.
- Лог: `/var/log/hermes-setup.log`.
- Статус модулей: `sudo bash scripts/install.sh --list`.
- Проверка состояния: `sudo -iu hermes bash ~/hermes-setup/scripts/tools/healthcheck.sh` (путь зависит от того, где лежит папка).

**Ожидаемый результат:** после каждого модуля строка `[OK] Модуль ... готов`. Если появилась ошибка: ничего не ломайте, перешлите последние 30 строк лога или смотрите docs/12.
