# 11. Hermes Android

Неофициальный клиент: https://github.com/rusty4444/hermes-android (читайте страницу Releases, ставьте последнюю стабильную версию, сверяйте SHA-256 файла с указанным в релизе).

Клиент работает по локальной сети или через Tailscale. Мы используем Tailscale: порты не открываются в интернет.

1. На сервере: `sudo bash scripts/install.sh --only 09` → откройте ссылку входа, зарегистрируйтесь в Tailscale (бесплатно).
2. На телефоне: установите приложение Tailscale и войдите в **тот же** аккаунт.
3. Установите APK Hermes Android.
4. В приложении:
   - адрес сервера: tailscale-адрес из вывода модуля 09 (вида 100.x.y.z);
   - Gateway: порт 8642, ключ `API_SERVER_KEY`;
   - Панель управления: порт 9119, токен `HERMES_DASHBOARD_SESSION_TOKEN`.
   Значения: `grep -E 'API_SERVER_KEY|DASHBOARD_SESSION_TOKEN' ~/.hermes/.env` (не показывайте их посторонним). [СКРИН: настройки приложения]
5. Отправьте тестовое сообщение: именно отправка проверяет работу обоих портов.

Не работает: `ss -tlnp | grep -E '8642|9119'` (должен быть адрес Tailscale, не 0.0.0.0); на телефоне включён Tailscale.
