# 01. Покупка VPS

## Требования
- **Ubuntu 24.04** (рекомендуется; на 22.04 не работает голос) или 22.04, чистая установка.
- 2 vCPU / 4 ГБ RAM / 40 ГБ диска (минимум); лучше 4 vCPU / 8 ГБ / 60 ГБ.
- Публичный IPv4, доступ по SSH.
- Локация: для Claude и большинства сервисов подойдёт Европа (например Амстердам).

## Шаги (на примере HOSTKEY, у других хостингов похоже)
1. Зарегистрируйтесь на сайте хостинга и пополните баланс. [СКРИН: страница заказа VPS]
2. Выберите тариф по требованиям выше, образ **Ubuntu 24.04**, локацию.
3. Заказ → через несколько минут придёт письмо: **IP-адрес**, логин (`root`), пароль. Сохраните.
4. Убедитесь, что в панели управления есть кнопка перезагрузки и консоль: пригодится, если что-то пойдёт не так.

**Ожидаемый результат:** у вас есть IP, логин root и пароль.

## Что подготовить заранее
- Подписка Claude Pro или Max (claude.ai).
- Аккаунт Яндекса.
- По желанию: Telegram, телефон Android.
