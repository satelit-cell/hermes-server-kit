# 05. Вход в Claude через рабочий стол (и KYC)

Зачем рабочий стол: вход в Claude и проверка личности делаются в браузере. На сервере браузера нет, поэтому мы ставим лёгкий рабочий стол (xfce) и подключаемся к нему по RDP **через SSH-туннель**: порт 3389 в интернет не открыт.

## Шаги
1. Установите модуль 03 (он спросит пароль для рабочего стола).
2. На ПК откройте **отдельное** окно PowerShell и запустите туннель (окно не закрывайте):
   ```powershell
   ssh -L 3389:127.0.0.1:3389 hermes@<IP-СЕРВЕРА>
   ```
3. Win → введите `mstsc` → «Подключение к удалённому рабочему столу». Адрес `127.0.0.1`, пользователь `hermes`, пароль из модуля 03. [СКРИН: окно mstsc]
4. На рабочем столе откройте терминал (значок xfce Terminal) и выполните:
   ```bash
   claude
   ```
   Claude CLI покажет ссылку входа. Откроется браузер Firefox: войдите в свой аккаунт Claude, пройдите KYC, если потребуется, разрешите доступ. [СКРИН: страница входа]
5. Когда CLI напишет, что вход выполнен, закройте его (Ctrl+C) и выйдите из RDP.
6. На сервере повторно запустите модуль: `sudo bash scripts/install.sh --only 03` (он включит провайдера подписки Claude в Hermes).
7. Освободите память (по желанию):
   ```bash
   sudo bash scripts/tools/rdp-off.sh
   ```
   Включить снова: `sudo bash scripts/tools/rdp-on.sh`.

## Проверка
`claude auth status` и `sudo -iu hermes hermes doctor`.

## Если не получается
- Чёрный экран после входа по RDP: выйдите, зайдите заново; убедитесь, что в домашней папке есть файл `.xsession` с текстом `startxfce4`.
- Окно RDP просит пароль и не принимает: пароль задаёт модуль 03 для пользователя hermes; сменить: `sudo passwd hermes`.
- Firefox не стартует: откройте ссылку входа в браузере на своём ПК и скопируйте код обратно в терминал на сервере.
