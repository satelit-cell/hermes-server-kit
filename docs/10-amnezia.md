# 10. Amnezia VPN

Amnezia — VPN, который сам разворачивается на вашем сервере. Нужен для безопасного доступа и обхода блокировок. Ставится с вашего ПК, скриптом на сервере не устанавливается.

1. Скачайте клиент для Windows: сайт https://amnezia.org или https://github.com/amnezia-vpn/amnezia-client/releases. [СКРИН: страница загрузки]
2. Запустите клиент → «Свой сервер» → IP сервера, пользователь `root`, пароль или ключ. [СКРИН: окно ввода сервера]
3. Выберите протокол **AmneziaWG** → установить (клиент сам поставит Docker и контейнер).
4. Подключитесь, откройте 2ip.ru: должен быть IP сервера.
5. (Необязательно) отключить вход в SSH по паролю: `sudo bash scripts/tools/harden-ssh.sh`. Делайте это ТОЛЬКО когда вход по ключу уже проверен.

Порт SSH (22) мы не закрываем: доступ по ключу достаточно безопасен, а закрытие порта может отрезать вас от сервера.
